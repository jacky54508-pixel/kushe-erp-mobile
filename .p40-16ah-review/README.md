## 與 P40-16AC 的差異

- P40-16AC：透過 **外部 Playwright Chrome 的 `page.pdf()`** 產生 PDF，證明 PDF-first 概念，但不是裝置端產生器。
- P40-16AH：獨立 `index.html` 載入**本地** `pdf-lib@1.17.1` 與 `@pdf-lib/fontkit@1.1.1` 的 UMD 腳本，由網頁 JS `PDFDocument.create()` 在瀏覽器記憶體產出 **真正 PDF bytes**；Playwright 只做測試瀏覽器驅動／回傳 bytes。Python PyMuPDF **獨立讀取輸出 PDF**，核對 A4、中文字、每筆戶別/項目、明細彙總、含稅總額、印章佔位、頁界與最小 8pt 字體。
- 測試用繁體中文字型由 CI 從 OS 安裝 `fonts-arphic-bsmi00lp`，複製到臨時本機測試目錄使用，測試結束立即刪除；**不 commit、不 upload、不提供字型檔下載**。所有套件版本只在 workflow 直接釘選，未建立 lockfile；若未來正式導入，必須採用 lockfile、SBOM 與套件安全審查。
- 測試原始物件刻意帶有 `PRIVATE-INVOICE`、`PRIVATE-BANK`、`PRIVATE-PAYROLL`、`PRIVATE-TOKEN` 哨兵，由前端公共 View 白名單剔除，不得進入 PDF；**這只是虛構投影測試**，不能替代正式帳務/跨區/歷史單測試。

## 預期驗收矩陣

| 虛構情境 | 預期 |
|---|---|
| 18 筆中文短品名 | 真正 A4 1 頁，保留 18 筆原明細、18 筆彙總 |
| 30 筆中文短品名 | 真正 A4 1 頁，保留 30 筆原明細、30 筆彙總 |
| 30 筆中文中長品名 | 真正 A4 1 頁（若無法裝入則嚴格 BLOCK，不移除內容） |
| 30 筆原明細、6 種項目 | 真正 A4 1 頁，彙總 6 種項目 |
| 30 筆特長品名 | 強制拒絕，不輸出不完整 PDF |
| 30 筆長備註 | 強制拒絕，不輸出不完整 PDF |
| 假選取區、金額不符、刪明細、內部資料混入公開備註 | 強制拒絕 |

測試包括 **1280px 電腦**與 **390px 手機模擬**（不是實體手機），允許的 PDF 及 PNG 僅保留 3 天 artifact；被拒絕的檔案不可上傳。

## 已知非生產限制

- 本原型並非**正式請款單的外觀**；真實公司抬頭/LOGO/大小章、完整金額項與所有 PDF 規則還沒整合。模擬章是中性矩形，不能冒用真實章。
- PDF 版型與既有 HTML 不同，正式資料的混合含/未稅、議價折讓、保留款、請款與發票、單筆/合併/跨區來源的精確計算與隱私尚未核對。
- 沒有在原 ERP 加按鈕，也不受現有登入授權／同步回滾規則保護；正式原列印 `window.print()`、`?print=1`、瀏覽器快捷列印都不受此原型限制。
- 任何由使用者修改瀏覽器記憶體／腳本的情況不構成可信財務簽證。本機產生 PDF 減少新增資料傳輸，不等同雲端權限驗證。
- 禁止讓 P40-16AH 草稿直接合併 main/beta；若驗收全部 PASS，只能繼續規劃下一個**獨立候選**，不可自行發布。
