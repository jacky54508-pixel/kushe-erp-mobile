## 先確認實際風險

`assets/js/billing-groups.js` 的 `printSaved(...,historyOnly=true)` 在「預覽／歷史版本」可啟動歷史路徑；正式 `assets/js/external-billing-print.js` 原歷史路徑輸出「原請款／發票對照」，含各來源案場與原票號。本次只修**歷史列印 HTML 顯示**，不改原來源快照、已保存對外文件版次、應收/收款/銀行、折讓、保留款、發票、薪資、抽成或 `main`。

## 候選實際差異

- 唯一受修改之既有檔案：`assets/js/external-billing-print.js`。**當前** `if (!payload.historical)` 對外單張模板路徑保持不動；歷史有效/封存文件仍走原先歷史排版，不強迫轉換不同稅別的舊 v1 保存內容。
- **歷史列印**移除原單/原發票明細表及原始開票日期，不輸出來源區域名稱、原發票號碼、收款明細、支票預留或銀行記錄。仍顯示原選定目標案場、完整施工列、**底部施工項目彙總**、保存的未稅/稅額/含稅/保留款/應收數值及原對外備註；標明「歷史保存版本，僅供查閱，非本次付款通知」。
