## 安全與商務限制（全部仍為正式發布阻擋）

1. **本試驗沒有真正 ERP 存取、授權、同步驗收。** `approvedByTrustedCaller:true` 僅供測試，不能在正式程式中當成 MFA 或帳務來源可信的證據。
2. 正式公司抬頭／LOGO／大小章皆未使用；本機 A4 是簡化的**新樣版**，不是舊對外 PDF 已做到逐字逐像素相容。
3. 本測試只支援部分單筆情境；普通合併 `kushe-combined-billing-v1`、跨區合併、原始歷史保存與內部多發票各需單獨轉接、權限及隱私驗證，**目前仍阻擋**。
4. 真實的折讓、混合計價、免開發票/已開、保留款稅基、歷史補登與員工抽成等業務金額**不得由 PDF 重新計算**；實際帳務逐筆對照尚未完成。本試驗只驗證純虛構案例。
5. 目前瀏覽器不提供「阻止所有 File → Print、快捷鍵、舊 `?print=1`」的保證。本原型完全沒有整合到正式入口；不能聲稱正式 ERP 已新增 A4 頁數阻擋。
6. 手機只是模擬寬度，沒有實體手機列印與建商對外驗收。測試也沒有取得並使用使用者當下最新 `SYNCED` 或完整可還原正式備份，所以**不能發佈正式版**。
