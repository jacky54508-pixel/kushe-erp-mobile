# P41 合約式報價單：補充說明孤頁與編號修正

記錄日期：2026-11-25。

## 基準、目標與範圍

固定正式基準為 `49edb30257707a786329d19207b92fec951d3906`；候選分支為 `p41-quote-contract-spacing-20261125`。使用者回報正式版在明細較高時，施工範圍留在第一頁、兩行補充被擠到第二頁，付款條款卻強制另起第三頁，形成大面積空白。前一輪合成案例只有兩列備用單價，沒有涵蓋全列備用單價與 Windows 字型所造成的高度差。

修正移除額外加入的「一、施工明細」「二、施工範圍」編號，使用清楚的無編號大標題；原備註內的一至七等條款編號維持原文。調整頁首、表格及備註的純留白，不縮小文字。補充說明若仍須續頁，付款條款可接在該續頁下方，不再無條件另起一張。

原公司 LOGO、大小章、明細列、單價、數量、計價模式和備註原文保留。此次為已授權發布之合約模板的同範圍缺陷修正，仍經獨立候選、來源核對、Windows／Linux 瀏覽器驗證與 PR 合併流程。

產品變更僅限 `billing-print.html` 與既有 `assets/js/p41-quote-pagination.js`、`assets/css/p41-quote-pagination.css`。其餘變更僅允許清單中的驗收腳本、此紀錄及 `.github/workflows/p41-quote-pagination.yml`。來源門檻要求正式 main 未偏離固定基準、基準為候選祖先、分支名稱完全相符及沒有清單外變更。Store、報價儲存、請款資料、抽成、薪資、銀行與部署工作流程不在變更範圍。

CI 僅有 contents: read 權限，沒有正式部署步驟。候選及本機匯出工具不代表已合併或發布。

## 顯示與原文核對

採實體 A4 頁面及系統明體字型，不新增網路字型。表格文字與備註正文至少 10.5pt，表頭至少 10pt；備用單價提示使用次要字級。列印比例維持 1。

只有完整獨立的「工程請款及付款約定條款」等明確標題觸發條款續頁。僅辨識末尾「特殊品項」與「非人為…保固」短補充行供版面重新安排。未知標題和正文中的相似片語保留一般備註處理。

每個備註顯示片段保留 UTF-16 原始起訖位置；按來源順序重組必須與原備註完全一致，不能遺失、重複或改寫。配對 ** 可顯示粗體；內容首尾不可為空白、內文不可含星號或換行，標記不可鄰接額外星號或被奇數反斜線跳脫。其他標記和 HTML 外觀字串均保留文字。雙方各有一個空白簽署日期欄位，不推算或修改付款資料。

## 合成驗收與隱私

遠端案例使用新寫的虛構公司、客戶、案場、項目、數字與條款；LOGO／章圖亦使用合成 PNG。主案例只參照文件結構及大致長度：11 筆實做實算明細、範圍、7 組條款、2 行末尾補充。新增全 11 列備用單價、較長範圍與第一頁較擁擠的案例，在 Linux 與 Windows 的系統字型下核對頁數、原文及分頁。沒有提交使用者實際客戶、價格、條款、報價網址或原始 PDF。

- 主案例實際輸出正好 2 頁：首張為明細及範圍／補充，次張有完整條款標題、依序七個標題、原簽章區及雙方各一個日期欄位。
- 原始列、單位、數量、單價及金額完整；實做實算維持四欄而不新增總額，一般與混合計價維持原始合計且不重複。
- 原始備註區間覆蓋來源一次，獨立 Python 規則核對可見內容只移除合法粗體標記。一般純文字保留直接串接比對；CRLF、獨立 CR、emoji 與尾端空白不改寫。
- 短單、空備註、純空白、未知標題、惡意外觀文字、未配對與跳脫標記、跨頁長段落、多筆一般與混合報價分別驗收。
- 桌面、390px 窄螢幕及列印無水平或頁內溢出；整頁完整位於預覽容器。原 LOGO 已載入且尺寸為正，完整位於 contain 圖框內。
- 真實 Chromium A4 PDF 頁數與可見頁數一致；Poppler 核對每頁完整儲存格及備註片段，並保存原始順序及版面順序文字診斷。
- 單筆、合併請款與固定正式基準的 DOM、文字、桌面／手機 PNG、PDF 頁數及文字相同。基準已含舊分頁 JS／CSS，伺服器載入全部基準資產。
- 本機匯出工具使用同一 JS／CSS，實際從 file origin 匯入合成報價，保留 CSP，驗證條款、特殊字串、原始資料與列印 PDF，無外部請求或儲存寫入。

每個案例獨立執行並保留失敗，任一失敗即阻擋整體通過。CI 保存結果 JSON、原文及來源片段證據、畫面、PDF 與文字診斷；就緒或結構提早失敗也嘗試保存 PNG、DOM、PDF。實際結果以候選 commit 的遠端 Chrome CI 產物為準，本紀錄不預先宣告通過或發布。
