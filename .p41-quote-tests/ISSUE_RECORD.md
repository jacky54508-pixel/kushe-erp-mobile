# P41 報價單急件：長備註與 A4 分頁

記錄日期：2026-11-24（Asia/Taipei）。

## 使用者回報與目標

使用者回報報價預覽右側超出白色紙張、整份字體過小，備註很長，要求按段落分頁並盡快完成，以便對外提供報價單。

本次明確採用「短單一頁、長單續頁」；沿用薄荷色報價風格，保留施工項目、數量、單價、金額、計價模式、備註全文及原公司 LOGO／大小章。付款條款只改顯示，不自動縮寫、改約定或重編號。

## 根因

正式 main `edf1c1886aac09958caa9e4b304502cca44f6937` 的 `billing-print.html` 中，報價專用 `fitQuotationToA4()` 依內容高度縮小 `zoom`，又把寬度設為 `100 / scale %`；只核對高度，未核對水平範圍。長備註會觸發整份報價單縮小及寬度擴張，且 `.note` 原本禁止區塊內分頁。

## 本次改動

- 報價使用實際 A4 頁面，按明細列與備註段落分頁。
- 短備註與簽章能放在當頁時保留當頁；放不下的長備註完整移到續頁，第一頁提示詳細備註與簽章見續頁。
- 條款標題與下一段盡量同頁；超過一整頁的單段文字才進一步拆分，保持所有字元與順序。
- 延續原表格欄位、單價、總計與實做實算顯示；頁尾加頁次。
- 分頁後核對所有原始明細列、備註全文與原始圖片節點。
- 提供由同一渲染程式產生的本機匯出檔，可貼上既有報價預覽網址，在本機產生分頁 PDF，不連線 ERP 或修改資料。

## 實作與發布範圍

候選分支：`p41-quote-pagination-20261124`，從上述正式 commit 建立。

產品變更僅限 `billing-print.html` 的報價流程及兩個新增的報價專用 JS／CSS。`quotations.js`、Store、請款流程與財務資料不修改。合成驗收與工具建立程序位於本目錄；CI 僅有讀取權限，不含部署步驟。

既有正式發布界線仍適用：這次候選修改與本機匯出檔不代表已合併或部署正式站。

## 驗收重點

- 11 筆實做實算明細加長條款：完整分頁、無水平溢出、保留四欄且不顯示總額。
- 短報價一頁；多筆一般／混合報價可續頁，所有原始金額及合計保留且不重複。
- 備註全文與原始字元一致；含特殊符號或 HTML 字串時只當文字顯示。
- 桌面、窄螢幕與實際 Chromium A4 PDF 核對。
- 原請款頁面與固定基準的文字及畫面一致。
- 本機匯出檔僅接受報價預覽，完整保留內容，沒有對外請求或儲存寫入。

實際驗收結果以候選 commit 的 CI、PDF／畫面產物及結果 JSON 為準；本紀錄不預先宣告測試通過。
