# P40-16C｜議價折讓「會計核定、不可重複入帳、回沖」安全設計

> 狀態：**純模擬、唯讀驗證**。未修改正式 ERP、財務主檔、資料庫、發票、請款 PDF；任何真正入帳都尚未實作或授權。

## 一、已確認的 ERP 既有業務規則

1. P40-15C 已可在正式站對單筆及合併請款試算總折讓，**不會儲存**。現有合併文件僅提供對外展示，兩張原請款與其應收及發票仍為唯一帳務來源。
2. P40-16A/B 在隔離分支使用純函式核對每張原單的未稅、稅額、含稅、保留款與應收分攤；不自動按比例攤折讓，沒有持久化或入帳。
3. 支票待兌現不代表銀行已收款，也不能提前沖銷應收或解鎖抽成。抽成目前依原未稅來源及收款邏輯處理，未確認折讓是否影響薪資前應維持原帳。
4. 當原單已開立發票或已有款項收回，折讓還涉及外部憑證／申報及獨立收款處理，不能直接把歷史請款改成較低金額。

## 二、台灣銷貨折讓的財政部依據（供會計核定，不是自動裁定）

- 財政部稅務入口網〈營業人開立發票後，發生銷貨退回或折讓，應如何處理？〉（2025-10-09 更新）
  https://www.etax.nat.gov.tw/etwmain/tax-info/understanding/tax-q-and-a/national/business-tax/invoice/NELbx22
- 財政部〈統一發票使用辦法〉第 20 條及第 20-1 條（查看當期最新法規）
  https://law-out.mof.gov.tw/LawContent.aspx?id=FL006084
- 財政部電子發票實施作業要點
  https://law-out.mof.gov.tw/LawContent.aspx?id=FL041411

已開發票後的折讓，應區分：**是否已申報、買受人是營業人還是非營業人、原開立的是紙本或電子發票**。電子發票折讓涉及電子方式開立／傳輸／接收折讓證明單及平台存證。ERP 僅可記錄有無經人工核對的憑據，不能宣稱替代官方開立／存證。退回、折讓憑證格式與申報期仍由會計依實際案件確認。

## 三、會計核定流程（全部為獨立唯讀審查）

| 關卡 | 必須具備 | 失敗時 |
|---|---|---|
| A. 單據來源 | 原請款 ID、應收 ID、合併文件版本、完整快照一致 | 停止 |
| B. 核定授權 | 建商核定日期、事由、簽認依據、負責人與會計複核 | 停止 |
| C. 金額分攤 | 每張原單的未稅、稅額、含稅、保留款、應收差額完整勾稽 | 停止 |
| D. 稅務憑據 | 每張原單開票狀態、申報狀態、買方類別、人工確認紀錄；已開票須原票號與折讓證據參照 | 停止 |
| E. 已收款／票據 | 無未處理之收款、保留款收回、支票預留；若有需另立受控流程 | 停止 |
| F. 重複事件 | 唯一請款文件與操作鍵；已有折讓事件需核對前次金額和沖回歷史 | 停止 |
| G. 人員薪資 | 未經明確核定前，薪資及抽成不自動重新計算 | 停止 |
| H. 未來入帳 | 交易鎖、CAS、唯一操作鍵、追加式調整流水、有效回沖、驗收與正式授權 | **本階段沒有入帳能力** |

**注意：** 上述證據即使全部人工填入，只能達到「可進入下一輪人工審核」；不能據此自動認定稅務文件有效，更不能直接過帳。

## 四、未來應採用的事件與回沖模型（尚未實作）

建議未來建立單獨的不可變事件，所有原始資料不得覆寫：

```text
ConcessionIntent (核定草稿) -> AccountantReview -> FinancialReview
  -> [未來才可實作] PostedAdjustment (不可變事件)
  -> [需要回沖時] ReversalAdjustment (獨立反向事件，引用原事件)
```

每一事件至少須保留：`documentId`、`sourceBillingIds`、`receivableIds`、`documentRevision`、`expectedSnapshot`、`operationKey`、折讓逐張分攤、人工核定依據、稅務憑證、授權人、時間、對帳後餘額。重送必須識別操作鍵、比對內容雜湊；不同內容共用操作鍵要失敗，同內容重送不得生成第二次折讓。回沖新增對應事件，不刪除或更改原來的憑證、銀行流水或員工薪資。

## 五、案例與人工待決項目

整張合併試算：NT$632,100 → NT$600,000，折讓 NT$32,100；兩張原單、18 項對外明細，其中一張有開票。本階段僅**虛構測試**使用這些金額。以下四個事項需人工確定後才能考慮下一階段：

1. 折讓 32,100 的**逐張來源分配**及逐張營業稅、保留款、應收對應，不得只看合併總額。
2. 已開票的原單是否已申報、買受人身分、電子或紙本折讓憑證、是否完成法規要求的流程。
3. 若先前收款、支票或保留款已處理，如何建立**獨立調整或退款事件**，不得直接修改原銀行交易。
4. 抽成基準：已付或已計薪的抽成是否保持原額、哪些尚未付款的抽成得另行調整，應由負責人另行確認。
