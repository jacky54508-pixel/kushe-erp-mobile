# P40-16CJ｜修正「預覽有顏色、匯出 PDF 變白」問題（隔離候選）

## 使用者實機症狀
- 同一筆請款單：螢幕預覽保留深藍表頭、淺薄荷色戶別與施工項目、青綠色應收欄；按「匯出 PDF／列印」存成 PDF 時，這些底色被移除。
- 內容數量金額與公司 LOGO／大小章仍可見，符合瀏覽器在**背景圖形未勾選**時省略 CSS 背景的常見情況。
- 原正式 ERP 已於 P40-16CI 發布，**不可再修改任何既有帳務**。

## 最小修正
僅在 `assets/css/p40-16cd-mint-quotation-billing.css` **附加一段 @media print**，針對 `#paper.billing-document` 及 `#paper.quotation-document` 和後代套用 `print-color-adjust: exact !important` 及其 WebKit 相容寫法。
這是印刷時的繪色偏好，不更改報價、稅額、保留款、數量、單價、合併原始明細、頁面結構、簽章、ERP Store、資料庫或雲端同步。

## 驗收
- 真實 Chromium、同一假請款資料產生**背景圖形開／關**兩份 PDF。
- 在測試頁人工注入 **economy 對照樣式**，證明能重現舊版的底色消失；注入只在假測試程序，不進入 ERP 正式程式。
- 假一般請款、報價及合併請款皆核對 A4 單頁、公司 LOGO／大小章、項目、金額、隱私不外顯；比較 PPM 每像素差異，背景關時的新版 PDF 應接近背景開時，而舊版 economy 對照明顯不同。
- 復測 P40-16CD 八組 PDF、P40-16CE 六組高密度／壓力 PDF，以及 14 項一次性安全列印測試。
