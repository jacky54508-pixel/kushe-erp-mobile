# 酷舍 ERP 新版首頁 Dashboard

這是與舊正式版完全分離的新版首頁，用來驗收已正式確認的 Dashboard 與共用介面。

## 本階段內容

- 依確認圖實作的首頁總覽與共用 ERP Layout。
- 桌面可收合側欄、平板與手機抽屜選單。
- 頂部快速搜尋、通知、使用者選單、月份與統計週期控制。
- 六項核心 KPI：銀行總餘額、本月營業額、本月已收、未收帳款、應付帳款、本月淨現金流。
- 月／季／年營業額趨勢。
- 本月收款結構、收款進度與應收回收率。
- 案場經營狀況 TOP 6。
- 待辦與異常提醒。
- 快速操作與薪資摘要。
- 使用既有 ERP 真實資料；沒有資料時不產生假數字。

## 開啟方式

直接開啟 `index.html`。若要讀取瀏覽器即時資料，請使用與舊版相同的瀏覽器及使用者環境；若即時資料不可用，會讀取現有 ERP 最新備份快照。

## 資料安全

- 新版首頁只讀取正式版的 `KuSheERP25_EMERGENCY` 自動儲存資料，不會改寫舊資料。
- 本階段不修改請款、稅額、抽成、薪資、應收應付、銀行及 PDF 邏輯。
- 舊正式版保留原狀。

## 文件

- `CHANGELOG_PHASE1.md`：檔案與資料來源變更紀錄。
- `QA_REPORT.md`：第一階段檢查與實際環境驗收項目。

完成首頁驗收前，不進行第二階段其他模組重構。
